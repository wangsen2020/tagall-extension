# Privacy policy draft

TagAll works only when the user opens WhatsApp Web. To prepare group mentions, the extension reads participant labels rendered in the currently active group conversation and writes the resulting mentions into the message composer.

TagAll does not transmit, sell, share, store remotely, or use participant labels, message text, phone numbers, chat content, or any other personal communications. The optional display setting is stored in Chrome Sync storage. TagAll does not send messages automatically.

Before production publication, replace this draft with a hosted privacy-policy URL that includes the publisher's legal name and support contact.
